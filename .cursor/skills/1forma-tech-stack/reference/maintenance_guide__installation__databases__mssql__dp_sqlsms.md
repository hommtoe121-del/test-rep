# Создание новой таблицы БД в среде Microsoft SQL Server Management Studio

Источник: https://help.1forma.ru/maintenance_guide/installation/databases/mssql/dp_sqlsms/

Данная инструкция описывает создание пользовательской таблицы в базе данных 1Ф средствами SQL Server Management Studio (SSMS). Может потребоваться при настройке пользовательских отчётов или интеграций, работающих с дополнительными таблицами в базе D10Task.
 1. В обозревателе объектов установите соединение с экземпляром компонента SQL Server Database Engine и разверните его.
 2. Разверните папку Databases. Раскроется список существующих баз данных. Нам нужна база данных, связанная с приложением "Первая Форма". В стандартной сборке база данных называется D10Task.
 3. Разверните БД D10Task. В раскрывшемся списке выберите раздел Tables (Таблицы) и кликните по нему правой кнопкой мыши. В открывшемся контекстном меню выберите пункт "New table...
 4. Таким образом, создана новая таблица в существующей базе данных. Чтобы сохранить созданную таблицу, вызовите контекстное меню нажатием правой кнопки мыши и выберите действие "Сохранить" ("Save table.."). После этого будут доступны все стандартные действия над таблицами БД (заполнение, настройка связей столбцов, извлечение данных и т.д.).
