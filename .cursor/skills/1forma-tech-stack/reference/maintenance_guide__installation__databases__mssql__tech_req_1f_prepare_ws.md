# Установка компонентов Windows Server 2019

Источник: https://help.1forma.ru/maintenance_guide/installation/databases/mssql/tech_req_1f_prepare_ws/

1. После установки операционной системы установите роль веб-сервера с необходимыми компонентами и службами.
 Выбор компонентов: для Windows Server 2019 выберите Framework 4.8:
 Выбор служб ролей:
 В региональных настройках сервера установите системный язык — Русский.
 2. Установите .NET Framework 4.8. После установки обязательно загрузите все обновления.
 3. Установите обновления Windows Server.
 На сервер приложения необходимо устанавливать обновления после их появления.
 ℹ️ После завершения установки перезагрузите сервер
