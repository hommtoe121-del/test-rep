# Порядок обновления

Источник: https://help.1forma.ru/maintenance_guide/installation/application/iis-deployment/setup/update_order/

Для того, чтобы обновить приложение "Первая Форма" выполните следующие действия:
 1. Сделайте резервную копию базы данных

-  Зайдите в SQL server, выберите базу с названием D10Task.


-  Сделайте резервную копию базы. Для этого в контекстном меню выберите: Задачи -> Создать резервную копию. (Tasks -> Back Up)

  2. Сделайте резервную копию файлов приложения, находящихся, как правило, в папке 1Forma или TaskCenter, которая расположена по следующему пути: C:\inetpub\wwwroot.
 Самый простой способ создания резервной копии файлов приложения – копирование папки в текущую категорию.
 3. Распакуйте файлы обновления и скопируйте их в папку, для которой делали резервную копию (пункт 2). Обратите внимание, что при замене файлов приложения может понадобиться перезапуск служб IIS. Для этого в командной строке от имени администратора нужно выполнить команду iisreset (если нужно приостановить работу служб – "iisreset \stop", команда "iisreset \start" запустит службы IIS).
 4. Выполните файл nakat_webconfig_run.bat из папки приложения (по умолчанию C:\inetpub\wwwroot\1Forma\_nakat\DBMigrations).
 Обновление завершено.
 ℹ️ После обновления приложения рекомендуется очистить кэш. Для этого нажмите сочетание клавиш Ctrl+Shift+Delete, в появившемся окне отметьте параметр "Кэш" (Cache) и нажмите кнопку "Очистить все".
 ℹ️ При восстановлении базы из резервной копии необходимо заново зарегистрировать ASSEMBLY и создать служебные хранимые процедуры.
