# Диск

Источник: https://help.1forma.ru/domains/disk/business/

Диск — файловое хранилище 1Формы: папки, файлы, права доступа, журнал действий и связь с задачами. Документ описывает пользовательские сценарии и права; физическое хранение файлов — в домене files, административные настройки — в admin.md. Ниже — разделы диска, бизнес-правила, интерфейс, представление категории «Диск» и связи с другими доменами.

Диск — это файловое хранилище 1Формы: папки, файлы, права доступа, журнал действий и связь с задачами. Здесь описаны пользовательские сценарии и права; как файлы хранятся физически — в домене files, а административные настройки — в admin.md.

Система показывает пользователю системные разделы:
 Раздел Описание Мои файлы Личные файлы пользователя. Не видны другим, кроме прямых руководителей Общие файлы Совместное использование. По умолчанию все сотрудники компании могут создавать папки и файлы (признак «Сотрудник компании» — в настройках профиля). Не отображается для не-сотрудников. Подпапки наследуют права родительской по умолчанию Обмен файлами Раздел доступен всем зарегистрированным пользователям, но доступ к файлам и папкам — только у владельца и администраторов. Владелец может предоставить доступ как сотрудникам, так и внешним пользователям. Используется для передачи файлов внешним Файлы автоматизации Папки, привязанные к задачам через смарт-автоматизацию. Видны только сотрудникам компании с правами администратора. Содержит системную подпапку `Export configurations` для выгрузок конфигурации площадки Файлы замещаемых Содержимое «Моих файлов» замещаемых сотрудников в подпапках. Отображается при наличии замещения Файлы подчинённых Содержимое «Моих файлов» подчинённых в подпапках. Отображается у руководителей Видимость Диска в целом может быть ограничена через опцию «Функции Диска» в настройках рабочего места группы.

 Папка — базовый контейнер структуры диска:

- у папки есть владелец и иерархия (папки могут вкладываться друг в друга);

- доступ к папке определяется правами пользователя и группы.
  У каждого файла есть история версий. Пользователь работает с «файлом», но при каждой загрузке новой копии сохраняется отдельная версия — к ним можно вернуться.
 Файл может быть связан с задачей или дополнительным параметром:

- файл, вложенный в задачу;

- файл, вложенный в ДП типа «Файл»;

- папка Диска, привязанная к задаче.

Объём личного раздела «Мои файлы» ограничен. Лимит задаёт администратор; если он равен нулю, раздел «Мои файлы» скрывается.
 Папку можно привязать к задаче смарт-действием. Такая папка становится единым местом хранения файлов задачи и файловых ДП.
 Права к связанной папке формируются из прав к задаче — с учётом ролей, групп, подписок и замещения.
 Операции чтения и изменения файлов могут записываться в журнал действий Диска.
 В Диске видны только те папки и файлы, которые доступны пользователю.

К Диску относятся:

- навигация по папкам;

- действия с файлами и папками;

- доступность и права для пользователя;

- журнал действий с Диском.
  Физическое хранение файлов — это домен files: где и как хранятся файлы, форматы, конвертация, сжатие, внешние редакторы.
 Ссылки на файлы и папки Диска могут содержаться в комментариях к задачам. Такие ссылки отображаются как обычный кликабельный текст.

- Нажатие на ссылку, ведущую на папку, открывает эту папку в разделе Диск.

- Нажатие на ссылку, ведущую на файл, открывает боковую панель предварительного просмотра (если текущий контекст это поддерживает — например, в ленте или в карточке задачи).
  Ссылки формируются автоматически, в том числе в ответах AI-ассистента Анфисы при упоминании документов и файлов из Диска.

Диск можно открыть двумя способами:

- Из карточки задачи: тулбар → «Файлы» → «Диск» (открывается раздел, связанный с задачей).

- Из меню сервисов в панели навигации (общий Диск).

В правом верхнем углу — переключатель: Таблица / Список. Выбор сохраняется для каждого пользователя.
 Список: компактный формат с цветными иконками (зелёные — Excel, синие — Word, красные — изображения и PDF, серые — текстовые, архивы и неизвестные, оранжевые — папки), превью изображений вместо иконки, имя в одну строку с обрезкой. Дата и время показываются в двух отдельных колонках — «Дата» и «Время». Полное название и дата — в подсказке при наведении.
 Таблица: расширенный вид с колонками имени, размера, даты и других атрибутов. В колонке даты дополнительно отображается время, если файл загружен или изменён сегодня; для более ранних дат — только дата.
 Сначала папки, затем файлы. Можно отсортировать по алфавиту или по типу — клик по заголовку столбца меняет направление.
 Поиск запускается кнопкой в шапке контентной области Диска — рядом с хлебными крошками (путь к текущей папке).
 Поиск по всему доступному дисковому пространству (Мои файлы, Общие, Файлы автоматизации, Файлы подчинённых, Файлы замещаемых). Ищет по названию папок/файлов и по содержимому файлов. Результаты — на отдельном экране «Результат поиска»; выбор вида («Список» / «Таблица») сохраняется.
 Во время выполнения запроса отображается индикатор загрузки. При быстром наборе ответы на устаревшие запросы отбрасываются — в списке остаются результаты только по последнему введённому тексту.
 В результатах общего поиска у каждого объекта Диска отображается путь от корня — последовательность папок; он же выводится во всплывающей подсказке при наведении на результат. Переход из результата открывает папку напрямую без ручной навигации.
 В результатах поиска названия системных разделов («Мои файлы», «Общие файлы», «Обмен файлами» и др.) отображаются в том же виде, что и в основном интерфейсе Диска, в том числе во всплывающих подсказках при наведении на объект.

Поведение зависит от размера экрана:

- На больших экранах — клик по файлу открывает просмотрщик справа. Список сжимается, между ним и просмотрщиком — перетаскиваемый разделитель. До открытия файла панель скрыта. Закрытие: клик на другой элемент, снятие выделения или `Ctrl+E` / `Cmd+E`.

- На небольших экранах — файл открывается во весь экран в модальном окне (как в задачах и чатах).
  Разделы «Мои файлы», «Общие файлы», «Обмен файлами» можно раскрыть как дерево папок прямо в навигационной панели (шеврон слева от названия). В дереве — только папки, отсортированы по алфавиту; шеврон скрыт у папок без подпапок. Остальные системные разделы (Файлы автоматизации, замещаемых, подчинённых) — отдельной группой ниже без раскрытия.
 Адрес папки в ссылке формируется из имён папок (например, `…/Документы/Проекты`), а не из числовых идентификаторов. Это даёт понятную навигацию и читаемые ссылки; кириллица, пробелы и спецсимволы обрабатываются корректно. Старые ссылки автоматически перенаправляются на новый формат.
 Если папка была переименована, старая текстовая ссылка может перестать открывать нужный путь. В этом случае откройте папку через Диск и скопируйте новую ссылку повторно.
 При переходе в Диск система отображает дерево папок как единую иерархию, включая доступные пользователю вложенные папки. Если папка доступна через общие или специальные разделы Диска, она может быть показана вместе с промежуточными уровнями структуры, необходимыми для навигации.
 Для возврата на уровень выше — кнопка «Назад» слева от названия папки.
 Не рекомендуется называть папки в корне раздела только цифрами — может конфликтовать со служебными ID. Если такая папка открывается некорректно — переименовать.
 По умолчанию объём хранилища одного пользователя — 5 ГБ (лимит задаёт администратор). Если лимит равен нулю, раздел «Мои файлы» скрывается.
 Что учитывается в лимите: только файлы в папках, где пользователь является владельцем. Файлы из задач, чатов и папок, к которым пользователь имеет доступ без права владения, — не учитываются.
 Индикатор использования: в нижней части левой навигационной панели Диска отображается полоса с текущим объёмом занятого места. При наведении — подсказка: «Хранение учитывает все папки, где вы владелец папки».

Меню действий с папкой или файлом открывается по правому клику; то же меню доступно через кнопку «...» рядом с объектом.

По умолчанию права в «Общих файлах» имеют группа «Administrators», владелец папки и группа «Все пользователи». В группу «Все пользователи» входят только сотрудники компании; владелец и «Administrators» всегда сохраняют полные права. В разделе «Общие файлы» права можно выдавать только сотрудникам компании; для не-сотрудников — раздел «Обмен файлами».
 В окне выдачи доступа список получателей для внутренних разделов («Общие файлы», «Файлы подчинённых», «Файлы замещаемых») содержит только сотрудников компании и их группы; внешние пользователи доступны для выбора лишь в разделе «Обмен файлами».

 Правила выдачи прав:

- Владелец папки получает абсолютные права на все её дочерние элементы: подпапки и файлы.

- Пользователь не может сам себе выдать или забрать право — только владелец или администратор.

- Администраторы могут редактировать права всех пользователей и групп, за исключением своих собственных прав и прав владельца.

- Пользователь может выдавать другим только те права, которыми обладает сам (включая права через группы).

- Подпапка наследует права родителя при создании, но дальше не синхронизируется автоматически. Опция «Применить для всех вложенных папок» применяет права рекурсивно.

- Право «Чтение» на родительской папке расширяется на файлы внутри даже без явного указания.
  Расчёт эффективных прав в «Обмене файлами». Права пользователя на папку обмена считаются как объединение (побитовое ИЛИ) прав по тем записям ACL, где пользователь указан напрямую или состоит в группе из записи. Записи групп, в которых пользователь не состоит, игнорируются — пользователь не получает прав через группы, в которые не входит. Прямая выдача прав конкретному пользователю учитывается наравне с групповой. Владелец папки и администраторы получают полные права независимо от ACL. До 2.268.x этот фильтр в `FileExchangeFolder.GetUserPermissions` отсутствовал, и пользователю выдавался максимум прав любой группы из ACL независимо от членства — например, член группы «Клиенты» с правом «Просмотр» получал полные права группы «1Форма», если она тоже была в ACL папки.

В представлении категории Диск задачи отображаются в виде папок, название папки соответствует тексту задачи. При открытии папки показываются вложения задачи.
 В папке «Дополнительные параметры» создаются подпапки по названиям ДП; в них файлы сгруппированы по задачам, включая файлы из колонок ДП «Таблица».

 Навигация по папкам осуществляется стандартными переходами: нажатие на папку раскрывает её содержимое, кнопка «Назад» возвращает на уровень выше.
 Скачивание файлов доступно прямо из представления — нажмите на файл, чтобы открыть его или инициировать загрузку. Загрузка новых файлов из этого представления напрямую не предусмотрена: прикрепление файлов выполняется через карточку задачи.
 Административные настройки файлового хранилища — см. admin.md.
 Типичные действия пользователя с Диском:

- Открыть диск и перейти в нужный раздел.

- Создать папку, загрузить файл, выдать доступ.

- Вставить файл из диска в файловый ДП задачи.

- Работать с файлами через связанную папку задачи.

- Проверять аудит действий в журнале диска.

- Поделиться ссылкой на папку или файл Диска в комментарии к задаче.
  Поиск по Диску поддерживает:

- Полнотекстовый поиск по названиям папок и файлов и по содержимому файлов.

- Поиск по нескольким словам — с разделителем `|` (логическое ИЛИ).

- Фильтрацию результатов по расширению файлов, владельцу и дате изменения.
  Поиск выполняется по всему доступному дисковому пространству: «Мои файлы», «Общие файлы», «Файлы автоматизации», «Файлы подчинённых», «Файлы замещаемых».
 Результаты отображаются на отдельном экране «Результат поиска» с указанием пути от корня для каждого объекта. Переход из результата открывает папку напрямую без ручной навигации.
