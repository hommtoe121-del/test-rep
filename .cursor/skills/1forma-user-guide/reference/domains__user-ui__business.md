# Интерфейс пользователя

Источник: https://help.1forma.ru/domains/user-ui/business/

«Первая Форма» — конструктор: интерфейс подстраивается под задачи компании или подразделения (это настраивает администратор) и под предпочтения конкретного пользователя (через персональные настройки). Какие-то элементы могут скрываться, добавляться или менять расположение, поэтому ваш интерфейс может отличаться от описанного здесь типового. В системе используется современный интерфейс; предыдущая его версия описана отдельно.
 Интерфейс собирается на нескольких уровнях: глобальные настройки системы, настройки рабочего места группы и персональные настройки пользователя. Если пользователь состоит в нескольких группах, применяется рабочее место с наивысшим приоритетом.
 Полная карта элементов интерфейса с каноническими именами и синонимами — в справочнике Таксономия интерфейса 1Forma.

Панель навигации располагается сверху, слева или справа (выбор пользователя в настройках интерфейса). Иконки боковой панели выполняют роль сигнальных индикаторов — рядом отображается количество событий или задач.

Некоторые стандартные индикаторы администратор может скрыть. Помимо стандартных могут быть настроены дополнительные индикаторы, в том числе для определённых подразделений или групп (например, для техподдержки — индикатор с числом поступивших обращений, ожидающих обработки).
 В период замещения: рядом с количеством отображается число объектов замещаемого сотрудника в скобках.
 Системные баннеры: под панелью навигации могут отображаться цветные полосы с сообщениями о состоянии системы. Красный баннер означает, что потеряно соединение с сервером для обновлений в реальном времени — часть данных может не обновляться автоматически, пока связь не восстановится.

Панель по умолчанию раскрыта и закреплена слева. Её можно открепить — тогда она показывается только при наведении. Кнопка «Скрыть открепленное меню» появляется в панели навигации при открытом откреплённом состоянии.
 Блоки панели:

- Мои задачи — быстрый доступ к задачам по ролям (заказчик, исполнитель, акцептант). Справа от папок — счётчики: красный (просроченные), синий (новые), серый (всего). Счётчики обновляются динамически. При использовании смарт-доступов или гибких прав отображаются только задачи, где пользователь — заказчик, исполнитель или подписчик. Руководителям дополнительно показываются «Задачи подчинённых» и «Согласования подчинённых».

- Избранное — ссылки на объекты (задачи, категории, разделы, профили, отчёты, пространства, почтовые папки, внешние ссылки), цветовые метки, папки. Поддерживается перетаскивание.

- Категории — список доступных разделов и категорий в виде раскрытого дерева, без папки-обёртки. Заголовок группировки «Категории» отображается всегда.
  Каталог разделов внутри «Избранного». Специальный элемент избранного «Все разделы» (его добавляет администратор в избранное группы) раскрывается прямо внутри блока «Избранное» в полный каталог доступных пользователю разделов — в том же порядке дерева категорий и без папки-обёртки, как в блоке «Категории». Клик по разделу открывает его стандартное представление; состав каталога учитывает права пользователя. Так каталог оказывается выше личного избранного, а отдельный блок «Категории» при этом можно скрыть.
 Раскрытие веток дерева категорий переживает автоматическое обновление меню — например, после создания задачи в категории открытая ветка не сворачивается обратно до раздела.
 Чтобы открыть карточку задачи из Избранного в новой вкладке браузера, используйте `Ctrl + ЛКМ`.
 Рядом с каждым элементом Избранного отображается иконка его типа (категория, задача, пользователь и т.д.). Для элементов с неопределённым типом выводится единая стандартная иконка. Справа от названия, если задан цвет, отображается цветовая точка-индикатор.
 Совместное отображение Избранного и Категорий: когда у пользователя включены оба блока, они отображаются как независимые зоны. Зона избранного занимает высоту по содержимому, зона категорий начинается ниже и имеет собственный фон, растянутый до нижней границы страницы — это исключает пустое пространство, если дерево категорий короче экрана. Если виден только один из блоков, его фон растягивается на всю высоту боковой панели.
 В режиме замещения: отображается отдельный блок «Избранное (Фамилия Имя)» — избранное замещаемого сотрудника. Счётчики замещаемого показываются в скобках рядом с собственными.
 Поиск: по всем элементам меню (Мои задачи, ссылки, папки рабочего места группы, Избранное, дерево категорий). Найденные совпадения подсвечиваются бренд-цветом; подсветка действует и при открытой панели администратора. При фильтрации «только категории» или «только избранное» поиск применяется только к отображаемому разделу. `Esc` прекращает поиск.
 Поиск в дереве категорий ищет совпадения по двум атрибутам:

- по названию категории (конечного элемента дерева);

- по названию раздела (группы категорий).
  Поведение выдачи:

- Если найдена категория, дерево раскрывается до неё, и она подсвечивается.

- Если найден раздел, он отображается в результатах без автоматического раскрытия — нажмите на него, чтобы увидеть категории внутри. Подсвечивается сам раздел.

- Если категория попадает внутрь найденного раздела, она не дублируется отдельной строкой — путь до неё уже раскрыт через раздел.

- Если скрыты и Избранное, и Категории — отображаются только ссылки рабочей группы.

- Если в рабочей группе не настроены ссылки — остаётся только папка «Мои задачи».

 При показе меню «Избранное» боковая панель получает уже собранный и отфильтрованный список — вручную править его не нужно, но полезно знать правила:

- Узлы с одинаковыми параметрами (папка, тип ссылки, название, адрес и связанный объект) автоматически схлопываются в один; остаётся первый по порядку.

- Для зашифрованной задачи, к которой у пользователя нет доступа, в названии отображается стандартная заглушка «Текст задачи скрыт». Узел при этом остаётся в меню и не считается дублем одноимённой доступной задачи.

- При большом числе ссылок и/или наличии доверителей меню строится одним проходом с батчевой загрузкой данных задач и проверок доступа. Настраивать это отдельно не требуется.
  Скрытые узлы шифрованных задач и узлы-дубликаты не исчезают из БД и не теряют настроек; они лишь сворачиваются или маскируются при отображении для конкретного пользователя.

Работа с 1Формой ведётся в браузере или через нативное приложение.
 Поддерживаемые браузеры (последние версии): Google Chrome, Mozilla Firefox, Microsoft Edge, Safari. В других браузерах (например, Opera) возможна некорректная работа.
 Приложение из браузера (PWA): платформу можно установить как отдельное приложение на компьютер или мобильное устройство — по инструкции конкретного браузера.
 Мобильное приложение: на iOS / Android рекомендуется использовать мобильное приложение 1F Mobile, а не браузер устройства.
 Десктопное приложение — см. раздел «Десктопное приложение» ниже.
 Чтобы работать одновременно с двумя разными учётными записями, используйте разные браузеры или режим «Инкогнито».

Логотип компании или системы — это виртуальная кнопка: по клику выполняется переход на стартовую страницу.
 В большинстве случаев стартовая страница — это портал (дашборд) с портальными блоками. Структура портала:

- Группа — объединяет секции во вкладки.

- Секция — конкретный портал с заголовком или без.
  Приоритет стартовых страниц:

- Персональная настройка пользователя.

- Стартовая страница группы (если групп несколько — побеждает группа с наивысшим приоритетом).

- Глобальная стартовая страница системы.

Открываются во всплывающем окне (меню «Настройки» → «Настройки интерфейса»). Здесь можно выбрать цветовую тему и расположение панели навигации.

 Администратор может скрыть большинство настроек через опцию профиля «Разрешить кастомизировать UI» — тогда у пользователя останется только выбор светлой или тёмной темы.

Доступны две темы: светлая (по умолчанию) и тёмная.
