# Канбан

Источник: https://help.1forma.ru/domains/kanban/business/

Документ описывает канбан — визуальный режим работы с задачами в 1Форме. Канбан показывает распределение задач по статусам, позволяет менять статус перетаскиванием, фильтровать по ролям и ДП. Для администраторов (настройка) и пользователей (работа с досками). Разделы: бизнес-сценарии (канбан по маршруту, по Lookup, персональный), роли и права, представления «Канбан» и «Галерея», связи с другими доменами.
 Канбан используется как визуальный режим работы с задачами, когда важно:

- видеть распределение задач по статусам;

- быстро менять статус перетаскиванием карточек;

- фильтровать задачи по ролям и параметрам;

- контролировать поток работ без перехода в табличный вид.

Канбан категории: базовый сценарий — доска строится по статусам основного маршрута категории. При наличии основного маршрута колонками являются его статусы; статусы вне основного маршрута отображаются после основных; если основной маршрут не настроен, выводятся все статусы категории; список обновляется автоматически при создании задач и смене статуса.
 Канбан по Lookup-полю: доска строится по значению выбранного Lookup-параметра. Порядок колонок берётся из настройки Lookup-поля «Колонка сортировки»; если сортировка не настроена, порядок алфавитный; при переносе карточки между колонками меняется значение Lookup в задаче; есть колонка «Не заполнено» для задач без значения.
 Персональный канбан исполнителя: отдельный сценарий в профиле пользователя — доска задач, где пользователь является исполнителем. Лимиты: не более 100 задач на сегодня, 100 на завтра, 100 ближайших по сроку.

Доступные на доске действия зависят от прав пользователя в категории: базовые операции доступны пользователям с правом работы в категории; принудительная смена статуса — пользователям с правом «Администратор задач».
 С карточками на доске доступны действия: открытие полной карточки задачи по клику; быстрые действия из контекстного меню карточки; смена статуса перетаскиванием карточек; сортировка карточек внутри колонки (по сроку, приоритету, дате создания и др.); фильтрация карточек по ДП; выбор группировок и агрегатов (если настроено шаблоном).

В представлении категории Канбан задачи отображаются в виде колонок по статусам основного маршрута. Если основной маршрут не настроен — выводятся все статусы категории, а над блоками появляется сообщение «Не настроен основной маршрут».

Доска поддерживает масштабирование и набор фильтров, позволяющих ограничить набор отображаемых карточек.

- Масштаб регулируется кнопками увеличения/уменьшения; сброс к стандартному — по кнопке сброса.

- Доступны фильтры: по статусам основного маршрута («Все», «Активные», «Закрытые», «Отклонённые»), по преднастроенным отборам категории, по роли пользователя (исполнитель, заказчик, акцептант, «в параметрах»).

- Фильтрация по значениям дополнительных параметров — через фильтры-чипы над доской.

- Настройки фильтров сохраняются для текущей категории между сессиями.

Содержимое карточки конфигурируется администратором; приоритет и сроки выделяются визуально.

- Администратор может настроить произвольный набор полей в карточке (кроме заголовка) через шаблон карточки канбана.

- Исполнители отображаются аватарками; срок — бейджем (просроченные красным).

- Приоритет отображается цветовой индикацией и индикатором (5 уровней: критичный, высокий, обычный, низкий, самый низкий).

- Цвет колонки статуса соответствует цвету, настроенному администратором. Завершающие статусы всегда зелёные, отклоняющие — красные (для них смена цвета недоступна).

- Прогресс по подзадачам показывается бейджем «выполнено/всего» — по умолчанию виден на всех карточках, включая 0/0 у задач без подзадач.

Карточки допускают ручную сортировку внутри колонок и перенос между статусами перетаскиванием.

- Карточки можно сортировать внутри колонки по сроку, приоритету, дате создания и др. Сортировка выполняется в браузере и применяется ко всем колонкам одновременно. По умолчанию отключена; настройка сохраняется для текущей категории.

- Если администратор настроил фиксированный порядок сортировки на уровне вида канбана — перетаскивание внутри колонки недоступно.

- Смена статуса — перетаскиванием карточки между колонками. По умолчанию только в разрешённые переходы основного маршрута.

- Пользователи с правом «Администратор задач» могут включить режим принудительной смены статуса (меню «Прочее») — тогда перетаскивание работает между любыми статусами.

- В режиме принудительной смены статуса при перетаскивании доступные колонки-цели различаются визуально: статусы по маршруту задачи (штатный переход) и статусы вне маршрута (принудительный переход) подсвечиваются по-разному — видно, ведёт ли перенос по маршруту категории или это принудительный переход.
  Канбан по Lookup-полю: в меню «Статус» можно выбрать Lookup-параметр категории — тогда колонки строятся по его значениям. При переносе карточки между колонками меняется значение Lookup в задаче. Есть специальная колонка «Не заполнено» для задач без значения.

 Быстрые действия: клик по карточке открывает полную карточку задачи; правый клик открывает контекстное меню — добавить в избранное, изменить исполнителей, перенести срок, перейти по маршруту.

В представлении категории Галерея задачи отображаются сеткой карточек одинакового размера.

- По умолчанию в каждой карточке галереи отображаются заголовок задачи, исполнитель и срок.

- Администратор может расширить состав карточки дополнительными параметрами категории и обложкой, включая системные теги. Включить и отключить можно любые поля, кроме заголовка карточки.

- Настройка шаблона карточки выполняется администратором отдельно для вида «Галерея».

- Клик по карточке открывает задачу в текущей вкладке. Для открытия в новой вкладке используется контекстное меню (правая кнопка мыши по карточке).

Канбан интегрируется с несколькими доменами платформы: жизненным циклом задач, категориями, дополнительными параметрами, таблицами и профилями пользователей.

- tasks/business.md — жизненный цикл и переходы задач;

- categories/business.md — включение канбана и галереи как представлений категории;

- ext-params/business.md — канбан по Lookup и фильтрация по ДП;

- grids/business.md — другие представления категории (таблица);

- users-and-groups/business.md — персональный канбан пользователя.
