# Руководство администратора

Источник: https://help.1forma.ru/_guides-md/admin-guide-index/

Руководство для администраторов и настройщиков платформы «Первая Форма»: пользователи и права, категории и маршруты, дополнительные параметры, автоматизация, электронная подпись, интеграции и обслуживание системы.
 Слева — полное дерево разделов руководства. Ниже — быстрые переходы к частым темам настройки.

- Пользователи и группы — учётные записи, группы, роли

- Права доступа — модель прав, спецправа, перевоплощение

- Оргструктура — подразделения, руководители, синхронизация

- Категории и маршруты — жизненный цикл задач, переходы, статусы

- Форма задачи — карточка задачи, блоки, шаблоны

- Настройка ДП — типы, видимость, обязательность

- Справочник типов ДП — сводная по всем типам ДП

- Модель прав на ДП — доступ к параметрам

- Смарт-события — запуск действий по событию

- Смарт-действия — справочник всех действий

- Операторы и функции — синтаксис смарт-выражений

- Работа с типами ДП — обращение к параметрам в смарте

- Скрипты и движки — C#/Roslyn, Python, Lua, JS (Jint)

- Вызов веб-сервисов и API — HTTP- и API-запросы из действий

- Смарт-пакеты — создание, публикация и запуск пакетов действий

- Настройка ЭП: КриптоПро/РуТокен — плагины и рабочее место

- Подписи в маршруте — запрос подписей на переходах

- КриптоПро УЦ 2.0 — удостоверяющий центр

- JS и CSS вставки — кастомизация карточки задачи

- Методы JS API — обращение к полям и действиям карточки

- Подключить к портальной странице — скрипты на портале

- Миграция JS-вставок — переход на новую карточку

- Обмен с 1С: XML-теги — описание тегов обмена

- Интеграции — обзор — коннекторы, шина данных, секреты

- Шаблоны печатных документов — FR-шаблоны и экспорт

- Структура БД: схемы связей — ER-диаграммы таблиц

- Обслуживание БД — джобы, безопасная очистка таблиц

- Ссылки на объекты в адресной строке — deep links SPA

- Кастомные настройки (SettingsCustom) — тонкая настройка поведения
