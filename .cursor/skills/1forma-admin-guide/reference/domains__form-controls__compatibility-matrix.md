# Контролы формы — Матрица совместимости (MTF/NTF)

Источник: https://help.1forma.ru/domains/form-controls/compatibility-matrix/

Справочник совместимости типовых контролов формы (File, Lookup, MultiLookup, SelectUsers, Table EP) со старым и новым MTF и формой нового задачи (NTF). Описывает уровни поддержки, ключевые механизмы и практические выводы для диагностики инцидентов.
 Уровни поддержки: `Полная` — в рабочем контуре без ограничений; `Частичная` — с оговорками по настройкам/сценарию; `Ограниченная` — только в части сценариев.

Таблицы показывают уровень поддержки контролов и механизмов в каждом режиме формы.
 Группа Старый MTF Новый MTF NTF Комментарий File / MultiFile Полная Полная Частичная Часть сценариев зависит от create-flow и настроек показа в NTF Lookup Полная Полная Частичная Зависимости по связям/фильтрам в NTF чувствительны к контексту MultiLookup Полная Полная Частичная Схемы отображения и ToDo поддерживаются не одинаково во всех режимах SelectUsers Полная Полная Частичная В NTF чаще используется упрощенный поток выбора до создания задачи Table EP Ограниченная Полная Частичная Полноценный интерактивный сценарий в основном после создания задачи; кнопка «Множественный выбор» в NTF не отображается Поддержка ключевых механизмов формы по режимам рендера.
 Механизм Старый MTF Новый MTF NTF Валидация обязательности Полная Полная Полная Readonly/hidden режимы Полная Полная Частичная Pull-обновление после save Полная Полная Полная Realtime обновления (табличный ДП) Ограниченная Полная Ограниченная Массовый upload файлов Полная Полная Частичная Каскадные связи Lookup Полная Полная Частичная Практические выводы для поддержки:

- При инцидентах в NTF сначала проверять, поддерживается ли сценарий до фактического создания задачи.

- При расхождениях старый/new MTF ориентироваться на новый MTF как основной runtime.

- Для Table EP проблемы «только в NTF» часто связаны не с таблицей, а с create-flow и layout-ограничениями.

- Для Table EP: если на старом MTF вместо новой (Angular) таблицы отображается старая (legacy) — проверьте признак `UseAngularTable` в `ExtParamTableCommonSettings` (1 — новая реализация, 0 — старая).
