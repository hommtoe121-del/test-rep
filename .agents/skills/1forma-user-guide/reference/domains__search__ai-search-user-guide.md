# Умный AI-поиск

Источник: https://help.1forma.ru/domains/search/ai-search-user-guide/

Где найти: вкладка AI beta на странице поиска.
 Умный поиск понимает русский язык, названия категорий и разделов, дополнительные параметры, имена сотрудников и статусы. Он сам выбирает один из четырёх режимов по тексту запроса. Это отдельный режим основной страницы Поиск.

Режим переключается автоматически — по словам и формату запроса:
 Режим Что ищет Как активируется Пример Задачи Задачи по фильтрам и тексту По умолчанию `пресейлы клиент ромашка` Комментарии Комментарии по автору и тексту Слова: писал, обсуждал, комментарий, переписка `Сидоров писал про интеграцию` Содержимое файлов Текст внутри вложенных файлов Фразы: «в файлах», «по вложениям», «содержимое файлов» `в файлах протокол совещания` Файлы по имени Файлы по имени и расширению Расширение в запросе: .xlsx, .pdf, .docx и др. `отчёт.xlsx`

Всё, что не попало в другие режимы, ищет задачи. Система разбирает запрос на условия отбора — категория, исполнитель, параметры, статус, флаги, — а нераспознанный остаток ищет по тексту.

Напишите название — система его распознаёт:
 `пресейлы                          → задачи категории «Пресейлы»
ошибки хд                         → задачи категории «Ошибки ХД»
в разделе Поддержка               → все задачи раздела
в категории Мобильная разработка  → точное указание
` Склонения работают: «пресейлов», «мобильной разработке», «поддержки» — всё распознаётся.
 Укажите фамилию в любом падеже:
 `задачи Иванова             → задачи, где Иванов исполнитель
исполнитель Кузнецов       → явное указание роли
заказчик Иванова           → задачи, где Иванов заказчик
`

Если в запросе указана категория, можно отбирать задачи по её дополнительным параметрам. Система понимает названия параметров и их тип:
 `пресейлы клиент ромашка       → параметр «Клиент» содержит «ромашка»
клиенты КМ Смирнов            → параметр «КМ» = Смирнов
клиенты ЛК да                 → параметр-флажок «ЛК» = да
клиенты рейтинг А+            → параметр «Рейтинг» = «А+»
клиенты ИНН 7700000000        → параметр «ИНН» содержит «7700000000»
клиенты оборот > 100000       → параметр «Оборот» больше 100000
` Для числовых и денежных параметров работают сравнения: `>`, `<`, `>=`, `<=`, `=`, `≠`.
 Если после названия параметра не указано значение — найдутся задачи, где этот параметр заполнен:
 `пресейлы клиентский срок    → задачи, где параметр «Клиентский срок» заполнен
`

Чтобы отобрать задачи по статусу, укажите его в запросе:
 `в статусе Проведение        → задачи в статусе «Проведение»
со статусом Тестирование    → то же
` Слова-флаги сужают выборку по состоянию задачи и вашей роли в ней:
 `открытые                    → только открытые (по умолчанию)
закрытые                    → только закрытые
просроченные                → только просроченные
мои задачи                  → где я исполнитель
я автор                     → где я заказчик
я подписчик                 → где я подписчик
` Порядок выдачи тоже задаётся словами:
 `старые задачи ...           → сначала старые (по дате создания)
новые задачи ...            → сначала новые (по дате изменения)
` По умолчанию — по дате изменения, новые первыми.
 Всё перечисленное можно объединять в одном запросе:
 `просроченные пресейлы клиент ромашка   → флаг + категория + параметр
закрытые задачи Иванова старые         → флаг + исполнитель + сортировка
клиенты км смирнов ромашка             → категория + параметр + поиск по тексту
`

Включается словами-триггерами. Триггер убирается из запроса, остальное разбирается как обычно.
 Триггеры: писал, написал, обсуждал, говорил, сообщал, спрашивал, отвечал, комментировал (во всех формах: писала, писали, пишет…), а также комментарий, комменты, сообщение, переписка.
 `Сидоров писал про интеграцию    → комментарии Сидорова с текстом «интеграция»
комменты в категории Ошибки ХД  → комментарии в задачах категории
переписка Иванова               → комментарии Иванова
` В результатах — автор и текст комментария со ссылкой на задачу.

Ищет текст внутри вложенных файлов, включая распознанный текст со сканов и изображений. Включается явными фразами — просто слово «файл» не сработает.
 Триггеры: «в файлах», «в файле», «по файлам», «из файлов», «содержимое файлов», «в вложениях», «по вложениям».
 `в файлах протокол совещания     → файлы с текстом «протокол совещания» внутри
по вложениям акт приёмки        → то же
в файлах пресейлы бюджет        → файлы в категории «Пресейлы» со словом «бюджет»
` Учитываются формы слова: «протокол» найдёт «протоколы», «протоколом» и т.д.
 В результатах — имя файла со ссылкой на задачу.
 Слова «транскрипция», «ВКС», «расшифровка», «стенограмма», «видеоконференция», а также «протокол ВКС», «запись встречи», «запись созвона» включают специальный режим: поиск по содержимому файлов с именем «Видеоконференция от …». Явные триггеры вроде «в файлах» здесь не нужны.
 `транскрипция встречи с Ромашка    → файлы «Видеоконференция от…» с «Ромашка»
запись созвона апрель             → файлы «Видеоконференция от…» за апрель
`

Самый простой режим. Если в запросе есть расширение файла, весь запрос считается именем файла.
 Расширения: `.txt`, `.doc`, `.docx`, `.rtf`, `.pdf`, `.xls`, `.xlsx`, `.csv`, `.ppt`, `.pptx`, `.png`, `.jpg`, `.gif`, `.svg`, `.zip`, `.rar`, `.7z`, `.mp4`, `.mp3`, `.eml`, `.msg`, `.html`, `.xml`, `.json`, `.md`, `.sql` и другие (всего 39 форматов).
 `протокол.docx       → файлы с «протокол.docx» в имени
.xlsx               → все xlsx-файлы
report.pdf          → файлы с «report.pdf» в имени
акт сверки.pdf      → файлы с «акт сверки.pdf» в имени
` Этот режим не смешивается с другими и работает мгновенно, без обращения к AI.
 В результатах — имя файла со ссылкой на задачу.

Большинство запросов система обрабатывает мгновенно (доли секунды): как только в запросе распознаны категория, имя, параметр или статус, результат собирается напрямую — и всегда с учётом ваших прав доступа (вы видите только то, что вам доступно).
 Если по структурированному запросу ничего не нашлось, подключается полнотекстовый поиск с учётом форм слова. А для свободных формулировок (например, «условия поставки с отсрочкой») работает семантический поиск по смыслу — он точнее для расплывчатых запросов, но занимает 1–3 секунды.

Почему поиск вернул 0 результатов? Система могла принять слово за название категории или имя. Попробуйте упростить запрос или уточнить явным указанием: «в категории X» вместо просто «X».
 Почему долго? Если по структурированному запросу ничего не нашлось, подключается семантический поиск (1–3 секунды). Запросы с категорией, именем или параметром работают мгновенно.
 Важен ли регистр? Нет. «иванова», «Иванова», «ИВАНОВА» — одно и то же.
 Можно искать одновременно по задачам и файлам? Нет. Один запрос — один режим. Сделайте два отдельных запроса.
