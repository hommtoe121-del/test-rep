# Руководство пользователя

Источник: https://help.1forma.ru/_guides-md/user-guide-index/

Руководство для сотрудников, работающих в платформе «Первая Форма»: постановка и выполнение задач, общение, работа с файлами, календарём, отчётами и другими инструментами.
 Слева — полное дерево разделов руководства. Ниже — переход к основным темам.

- Задачи — создание и выполнение задач, маршруты, подписи, дополнительные параметры

- Общение — уведомления и лента, комментарии, чат, конференции

- Почта — встроенный почтовый клиент

- Представления — таблица, канбан, календарь, ресурсы и другие виды списка задач

- Файлы — вложения, просмотр и редактирование документов, Диск

- Отчёты — аналитика и системные отчёты

- Пространства — база знаний и статьи

- Проектное управление — проекты и диаграмма Ганта

- Поиск — быстрый и расширенный поиск

- Профиль и настройки — профиль пользователя, интерфейс, авторизация

- Организация — оргструктура компании

- Портал — рабочий стол с виджетами

- Мобильное приложение — работа с мобильного устройства

- AI-ассистент — помощник Анфиса
