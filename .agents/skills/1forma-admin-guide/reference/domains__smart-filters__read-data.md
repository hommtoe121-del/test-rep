# Чтение данных из Первой Формы

Источник: https://help.1forma.ru/domains/smart-filters/read-data/

Справочник по получению информации через смарт-выражения и смарт-фильтры 1Формы. Описывает атрибуты задач, пользователей, категорий и файлов; работу с дополнительными параметрами всех типов; коллекции, условную логику и типовые запросы. Для администраторов и разработчиков смарт-автоматизаций, настраивающих фильтры, вычисляемые поля и TSQL-запросы.

Смарт-выражения и смарт-фильтры — SQL-подобные запросы, построенные через конструктор 1Формы. Смарт-фильтры — частный случай смарт-выражений с результатом `true/false` или массивом элементов для фильтрации выборок.
 Смарт-выражения — SQL-подобные запросы, построенные через конструктор 1Ф. Возвращают значения любых типов.
 Смарт-фильтры — смарт-выражения, возвращающие `true/false` или массив элементов. Используются для фильтрации выборок.
 Оба инструмента могут работать в режимах:

- SMART — визуальный конструктор

- TSQL — прямой SQL-код

 ДП «Выбор нескольких задач из категории» (Multilookup) хранит значение — массив ID задач: `{12345, 67890, 34567}`

Для сложных случаев доступен прямой SQL.
 Чтение файлов задачи:
 `SELECT
    CAST(f.FileId AS varchar(MAX)) + '.' +
    CAST(f.LatestVersionId AS varchar(MAX)) AS FileRef
FROM FileStorageFiles f
JOIN FileStorageFileToTaskLinks l ON f.FileId = l.FileId
WHERE l.IsDeleted = 0
  AND l.TaskId = @TaskId
` Чтение файлов из файловых ДП:
 `SELECT
    CAST(f.FileId AS varchar(MAX)) + '.' +
    CAST(f.LatestVersionId AS varchar(MAX)) AS FileRef
FROM FileStorageFiles f
JOIN FileStorageFileToExtParamLinks l ON f.FileId = l.FileId
WHERE l.TaskId = @TaskId
  AND l.ExtParamId = @ExtParamId
` Таблицы файлового хранилища:
 Таблица Описание `FileStorageFiles` Метаданные файлов `FileStorageFileVersions` Версии файлов `FileStorageFileToTaskLinks` Связи файлов с задачами `FileStorageFileToExtParamLinks` Связи файлов с ДП `FileProviders` Провайдеры хранилища

Смарт-выражения возвращают значения перечисленных ниже типов и применяются для фильтрации, вычислений, валидации и отчётности.
 Тип Описание `String` Строка `Integer` Целое число `Decimal` Десятичная дробь `Boolean` Логическое (true/false) `DateTime` Дата и время `Entity.User` Пользователь `Entity.Task` Задача `Entity.File` Файл `Collection<T>` Коллекция объектов Смарт-выражения применяются для:

- Фильтрации задач — получение списка по условиям

- Вычисляемых полей — расчёт значений на лету

- Валидации — проверка условий перед действиями

- Отчётности — агрегация данных по коллекциям
  Рекомендации по составлению выражений:

- Используйте `IsNullString()` для защиты от null

- Проверяйте типы при конвертации

- Для сложных запросов предпочитайте TSQL

- Тестируйте выражения на реальных данных через интерфейс
