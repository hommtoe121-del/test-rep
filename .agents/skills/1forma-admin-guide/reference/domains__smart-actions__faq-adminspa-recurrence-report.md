# FAQ: где в AdminSPA «Отчёт по повторам»

Источник: https://help.1forma.ru/domains/smart-actions/faq-adminspa-recurrence-report/

Где в новом интерфейсе AdminSPA находится список смарт-расписаний (бывший «Отчёт по повторам» из dbadmin). Документ объясняет, как найти вкладку «Расписания» в модуле Автоматизация, чем она отличается от старого отчёта по повторам, и какие API-маршруты доступны для программного доступа. Также перечислены материалы для подготовки к диагностике и случаи, когда следует обращаться в поддержку 1Ф.

Пользователь спрашивает:

- «Где в новом интерфейсе отчёт по повторам?»

- «Раньше в dbadmin на вкладке категории был список задач с повторами, сейчас не найду»

- «AdminSPA — как посмотреть смарт-расписания?»
  Что понадобится:

- ID категории (SubcatID), по которой ищут отчёт

- Скриншот того, что видит пользователь (чтобы убедиться, что модуль «Автоматизация» доступен)
  В следующих случаях:

- Если вкладка «Расписания» не отображается — проверьте права пользователя на AdminSPA и модуль автоматизации

- Если расписание есть, но не выполняется — обратитесь в поддержку 1Ф
  Смежные разделы:

- Смарт-действия — администрирование (§ «Расписание»)

Вкладка «Отчет по повторам» находилась в редакторе категории. Показывала список задач, для которых настроено повторение.
 Функционал перенесён в модуль Автоматизация → вкладка «Расписания».
 Как найти:

- Открыть AdminSPA → Автоматизация (`/app/admin/smart-packs/{subcatId}`)

- Выбрать категорию

- Перейти на вкладку «Расписания» (SmartRecurrences)
  Чем новый раздел отличается от старого:
 Аспект Старый (dbadmin) Новый (AdminSPA) Что показывает Задачи с настроенным повторением Смарт-расписания (автоматизация пакетов действий) Уровень Задача Система (категория) Режимы — «Вне контекста задачи», «Для каждой задачи по фильтру» Программный доступ к расписаниям:
 Метод URL Назначение GET `/admin/smart/recurrences/list/{subcatId}` Список расписаний по категории GET `/admin/smart/recurrences/{id}` Детали расписания POST `/admin/smart/recurrences/create` Создание PUT `/admin/smart/recurrences/update/{id}` Обновление GET `/admin/smart/recurrences/execute/{id}` Ручной запуск GET `/admin/smart/recurrences/delete/{id}` Удаление
