# Порталы и виджеты — Решение проблем

Источник: https://help.1forma.ru/domains/portal/support-guide/

Типовые проблемы порталов и виджетов и их решение. Разделы организованы по типам проблем: виджеты, порталы, новости, пространства, JS-вставки, дашборды, смарт-действия и инфраструктура. Для каждой проблемы указаны симптом, что проверить и решение.
 Как пользоваться этим документом
 Секции организованы по типам проблем. Для каждой:

- Симптом — что описывает пользователь

- Что проверить — шаги диагностики

- Решение — что сделать

- Когда обращаться в поддержку 1Ф — если проблему не удаётся решить на месте

1.1 HTML-теги не обрабатываются / отображаются как текст
 Симптом: «в виджете Таблица перестали обрабатываться html-теги», «символы < и > не отображаются, текст пропадает».
 Что проверить:

- Версия системы — после обновления могло измениться поведение экранирования HTML

- Настройки виджета — включена ли опция отображения HTML в ячейках

- Содержимое ячеек — не используются ли спецсимволы `<`, `>` без экранирования
  Когда обращаться в поддержку 1Ф: если после обновления HTML перестал рендериться — баг.
 1.2 Фильтры в виджете не работают
 Симптом: «в фильтре виджета не отображается выбранный параметр», «не удаляются параметры фильтрации», «настройка фильтра на виджете».
 Что проверить:

- Тип фильтра — стандартный или пользовательский (хранимая процедура)

- Параметры фильтра — совпадают ли типы данных

- Версия системы
  1.3 Не переносится текст / не применяются настройки отображения
 Симптом: «чекбокс "Переносить текст на другую строку" не применяется».
 Что проверить:

- Версия системы

- Ширина колонки — не фиксирована ли

- Кеш — обновить страницу
  1.4 Закрепление колонок
 Симптом: «можно ли закрепить первые N колонок в виджете Таблица?»
 Решение: стандартной настройки закрепления колонок нет. Возможна доработка.
 1.5 Не выгружается Excel из портала
 Симптом: «не работает выгрузка в Excel из виджета / из портала».
 Что проверить:

- Хранимая процедура виджета — не возвращает ли ошибку

- Объём данных — не превышен ли лимит

- Права пользователя на экспорт
  1.6 Виджет-таблица или кастомная иерархия не грузит данные на PostgreSQL (ошибка `0A000`)
 Симптом: при открытии виджета-таблицы или кастомной иерархии — ошибка вида `0A000: cross-database references are not implemented: dbo.custom.<имя_функции>` (в интерфейсе и в Администрирование → Лог ошибок как `Npgsql.PostgresException ... 0A000`).
 Что проверить:

- Схема функции-источника данных: если объект в схеме, отличной от `dbo` (обычно `custom`), имя должно быть указано со схемой явно — `custom.имя_функции`.

- Версия платформы: корректная обработка квалифицированных имён для этого пути (виджеты и иерархии) — начиная со сборки 2.268; на более ранних версиях воспроизводится.

- Временный обходной путь до обновления: перенести или продублировать функцию в схему `dbo` и переключить виджет/иерархию на неё (устраняет симптом, не первопричину).
  1.7 В таблице пустые ячейки — значение появляется только после двойного клика
 Симптом: строки в виджете «Таблица» отрисовались, но значения в ячейках не видны; значение проявляется после двойного клика по ячейке и перехода в соседнюю.
 Что проверить:

- Настройку «Брать ссылку из» у проблемной колонки: ссылкой становится только строка-адрес (`http`/`https` или путь от `/`); идентификатор задачи, число или пустое значение адресом не являются.

- Версию платформы: с 2.268 значение ячейки выводится текстом даже при невалидном адресе; на более ранних сборках такая настройка даёт пустые ячейки.
  Решение: привести колонку-источник ссылки к строке-адресу либо очистить настройку «Брать ссылку из» у колонки — значения ячеек начнут отображаться сразу. Детализация (drill-down) настраивается отдельным полем и от этого не страдает.

2.1 Виджет Гант — нет колонок / не хватает доработок
 Симптом: «после обновления в виджете Гант нельзя выбрать колонки», «не хватает доработок в Ганте».
 Что проверить:

- Версия системы — Гант активно дорабатывается

- Настройки виджета — какие колонки ожидаются
  2.2 Значение колонки «Выполнено» в Ганте
 Симптом: «за что отвечает колонка "Выполнено"?»
 Решение: колонка «Выполнено» отображает процент выполнения задачи. Значение берётся из ДП, привязанного к этой колонке в настройках виджета.
 2.3 Кнопка-тикер — некорректная ссылка / локализация
 Симптом: «ссылка в кнопке-тикере ведёт не туда», «локализация не применяется для кнопки-тикера».
 Что проверить:

- URL в настройках тикера — корректен ли

- Локализация — заполнены ли переводы для нужного языка
  2.4 Виджет «Контакты» — нет данных по звонкам
 Симптом: «в виджете Контакты не отображаются данные по звонкам».
 Что проверить:

- Настройки интеграции с ВКС / телефонией

- Наличие данных в истории звонков
  2.5 Виджет «Группа виджетов» — некорректное отображение списка
 Симптом: «виджет Группа виджетов некорректно отображает список на новых порталах».
 Что проверить:

- Тип портальной страницы — dashboard, board, CSS Grid

- Настройки вложенных виджетов — корректны ли привязки

- Версия системы — поведение могло измениться после обновления
  2.6 Виджет не отображается в ДП «Большой текст с форматированием»
 Симптом: «виджет не показывается при открытии ДП через модальное окно».
 Что проверить:

- Тип виджета

- Контекст открытия — полная страница vs модальное окно

3.1 Ошибка при создании / добавлении портала
 Симптом: «при добавлении нового портала — ошибка», «не отображается портал после обновления».
 Что проверить:

- Текст ошибки

- Версия системы

- Права администратора
  3.2 Хранимая процедура портала — нет редактирования в AdminSPA
 Симптом: «в AdminSPA нет возможности отредактировать хранимую процедуру для портала, как в старой админке».
 Решение: в текущей версии AdminSPA редактирование хранимых процедур порталов ещё не реализовано. Использовать SSMS/pgAdmin для редактирования SP напрямую.
 3.3 Пакетная обработка из-под портала
 Симптом: «как сделать пакетную обработку из портала?»
 Решение: пакетная обработка из портала работает через виджет Таблица с включённой опцией множественного выбора. Настройки действий — в конфигурации виджета.
 3.4 Сертификат портала
 Симптом: «как обновить SSL-сертификат на портале?»
 Решение: сертификат настраивается на уровне веб-сервера (nginx/IIS), не в 1Ф. Передать администратору инфраструктуры.
 3.5 Права доступа к публикациям не сохраняются
 Симптом: «не сохраняются настройки прав доступа в публикации», «сохранение настроек права доступа к публикации не работает».
 Что проверить:

- Тип публикации — портал, пространство

- Роль пользователя — администратор публикации или нет

- Версия системы — поведение прав менялось в последних релизах
  Когда обращаться в поддержку 1Ф: если права не сохраняются при корректной роли — баг.
 3.6 CSSGrid — потеря привязки виджетов при переносе
 Симптом: «при переносе CSSGrid портала с настроенным виджетом не переносится сам виджет, отсутствует связь».
 Что проверить:

- Способ переноса — копирование категории, экспорт/импорт, ручной перенос

- Версия системы

- Наличие виджета в целевой категории после переноса
  Когда обращаться в поддержку 1Ф: если виджет теряется при копировании CSSGrid — баг.
 3.7 Создание учётных записей на портале
 Симптом: «как создать учётную запись на портале?», «настройка регистрации на портале».
 Решение: регистрация на портале настраивается через механизм внешних пользователей. Проверить: включена ли регистрация в настройках портала, настроены ли шаблоны уведомлений.
 3.8 Расширение рабочей области портала на весь экран
 Симптом: «как расширить рабочую область для порталов на весь экран?»
 Решение: ширина рабочей области портала определяется настройками шаблона страницы (CSS Grid / dashboard). Для расширения — изменить параметры сетки в настройках страницы или использовать CSS-вставку.

Симптом: «в выпадающем списке зависимого фильтра вместо значений вижу `Нет данных: <название>`».
 Решение: это штатное поведение с 2.268.349. Раньше пустой каскад показывал просто `Нет данных`, теперь к плейсхолдеру дописывается название самого параметра — чтобы было понятно, какой именно зависимый фильтр оказался пустым. Сам пустой результат — следствие выбранного значения родительского параметра: по нему смарт-выражение/статический набор каскада не вернули ни одной строки. Проверить:

- выбранное значение родительского фильтра — действительно ли по нему должны быть данные;

- настройку `Колонка родителя` (для смарт-набора) или `Ключ родителя` (для статического набора) у дочернего параметра — корректно ли указано поле привязки;

- результат смарт-выражения дочернего параметра с переданным `@eventParam2`, равным значению родителя.

Симптом: «при выборе значения в родительском dropdown-фильтре виджет возвращает ошибку 500», либо «значения в зависимом фильтре не блокируются/не скрываются, хотя должны — признак доступности не работает».
 Решение: оба симптома — следствие одного бага в бэкенде (перепутаны переменные при проверке на null), исправлено в сборке 2.268.378. Обновите систему. Если ошибка воспроизводится на актуальной версии — проверьте настройки «Колонка родителя»/«Колонка доступности» дочернего параметра (см. § «Каскадные выпадающие списки» выше) и обратитесь в поддержку 1Ф с логами.

4.1 Новости не отображаются в мобильном приложении
 Симптом: «не отображаются новости в МП на Android и iOS», «несогласованные новости видны в МП».
 Что проверить:

- Версия мобильного приложения

- Статус новости — опубликована ли / согласована ли

- Настройки видимости новости — для каких групп
  4.2 HTML-теги в заголовке / карточке новости
 Симптом: «в заголовке новости отображаются HTML-теги», «на карточке новости — null».
 Что проверить:

- Контекст отображения — через категории или через ленту

- Формат заголовка — нет ли «сырого» HTML
  Форматированный текст новости очищается при показе: безопасные теги отображаются, а скрипты и опасные атрибуты вырезаются и не исполняются в браузере.
 4.3 Пропала возможность ставить лайки
 Симптом: «не могу ставить лайки новостям, как раньше».
 Что проверить:

- Версия системы — настройка лайков могла переехать

- Настройки категории новостей
  4.4 Поиск по содержимому новостей / статей FAQ
 Симптом: «не работает поиск по содержимому новостей», «поиск по статьям FAQ не находит».
 Что проверить:

- Индексация — запущена ли полнотекстовая индексация

- Версия системы
  4.5 Тэги в заголовке новости
 Симптом: «как использовать тэги в заголовках новостей?»
 Решение: тэги для новостей настраиваются в категории новостей. Отображение тэгов зависит от версии.

5.1 Нет системных категорий пространств
 Симптом: «не вижу системных категорий пространств (раздела)».
 Что проверить:

- Версия системы

- Права пользователя

- Настройки модуля «Пространства»
  5.2 Подписи изображений в статьях сместились
 Симптом: «подписи изображений в статьях пространств стали располагаться не под изображениями».
 Что проверить:

- Версия системы — после обновления мог измениться стиль

- CSS — нет ли пользовательских стилей, конфликтующих с обновлением
  5.3 Поле «Контакты» в пространствах
 Симптом: «в чём смысл поля Контакты в пространствах?»
 Решение: поле «Контакты» привязывает к пространству ответственных лиц. Отображается как ссылка на профили пользователей в шапке пространства.
 5.4 Настройки категории не открываются из списка пространств
 Симптом: «не могу перейти в настройки категории из списка пространств, хотя из бокового меню — работает».
 Что проверить:

- URL — отличаются ли ссылки

- Версия системы

6.1 Ошибка при добавлении JS-вставки
 Симптом: «не могу поставить JS в портал», «ошибка при добавлении JS-вставки».
 Что проверить:

- Синтаксис JS — нет ли ошибок

- CSP (Content Security Policy) — не блокирует ли

- Версия системы
  6.2 Дублирование JS-вставок при копировании категории
 Симптом: «при копировании категории JS-вставки тоже копируются (дублируются)».
 Решение: ожидаемое поведение — при копировании категории копируются все связанные настройки, включая JS-вставки. Лишние вставки нужно удалить вручную.
 7. Дашборды в мобильном приложении
 7.1 Цвет текста на плитке дашборда не применяется
 Симптом: «в МП не применяются настройки цвета текста на плитке дашборда».
 Что проверить:

- Версия мобильного приложения

- Настройки плитки — какие цвета заданы
  7.2 Не добавляется виджет на портал
 Симптом: «не могу добавить виджет на портал».
 Что проверить:

- Тип виджета

- Тип страницы (dashboard, board, CSS Grid) — не все виджеты совместимы со всеми типами

- Права администратора портала
  8. Смарт-действия и публикации
 8.1 Смарт-действие через публикацию — ошибка
 Симптом: «смарт-действие "Резолюция подписи", вызванное через публикацию, возвращает ошибку».
 Что проверить:

- Тип смарт-действия — какое именно действие вызывается

- Контекст вызова — из карточки задачи работает, а из публикации — нет

- Версия системы — совместимость смарт-действий с публикациями ограничена
  Когда обращаться в поддержку 1Ф: если действие работает из карточки, но не из публикации — баг или ограничение платформы.
 8.2 Быстрый опрос на портале
 Симптом: «как настроить быстрый опрос на портале?», «не работает быстрый опрос».
 Что проверить:

- Настройки виджета опроса — привязан ли к категории

- Права пользователей на участие в опросе

- Версия системы — функционал может быть недоступен в старых версиях
  9. Инфраструктура порталов
 9.1 Настройки балансировщика для продуктивного портала
 Симптом: «как настроить балансировщик для продуктивного портала?», «портал работает нестабильно под нагрузкой».
 Решение: балансировка настраивается на уровне инфраструктуры (nginx/HAProxy), не в 1Ф. Передать администратору инфраструктуры. Ключевые моменты: sticky sessions, проброс заголовков, health checks.

Что зафиксировать при первичном разборе:

- Тип проблемы — виджет (Таблица/Гант/тикер/Группа виджетов), портал (создание/настройка/публикации), новости, пространства, JS-вставки, смарт-действия

- Версия системы

- Контекст — веб / мобильное приложение

- Тип портальной страницы — dashboard, board, CSS Grid

- Скриншот / текст ошибки

- Работало ли до обновления — если да, какая версия была до
  Когда обращаться в поддержку 1Ф

- HTML перестал рендериться в виджете после обновления (баг)

- Портал не отображается после обновления системы

- Массовые проблемы с виджетами после обновления

- Ошибка при создании портала при корректных настройках

- JS-вставки блокируются CSP

- Права доступа к публикациям не сохраняются при корректной роли

- CSSGrid теряет привязку виджетов при переносе

- Смарт-действие работает из карточки, но не из публикации
