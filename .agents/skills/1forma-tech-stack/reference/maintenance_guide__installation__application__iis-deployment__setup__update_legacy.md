# Обновление старой версии "Первой Формы"

Источник: https://help.1forma.ru/maintenance_guide/installation/application/iis-deployment/setup/update_legacy/

Чтобы произвести обновление уже установленной платформы "Первая Форма" выполните следующие действия:
 1. Ключ активации приложения хранится в базе данных (по умолчанию "D10Task") в таблице dbo.Settings в поле LicensesKey. Для успешного первого входа в программу его надо записать туда вручную и перезапустить пул приложения в IIS.
 2. Зайдите в "Первую Форму". Для входа используйте логин и пароль администратора.
 3. При первом входе в приложение "Первая Форма" выполняется первоначальная инициализация базы и наполнение ее начальными данными. Затем откройте консоль администратора.
 4. В интерфейсе администратора перейдите в пункт меню "Системные настройки" и откройте "Общие настройки приложения".
 5. В параметре "Категория для анонимных задач" выберите любое значение из выпадающего списка. В левом верхнем углу нажмите кнопку Сохранить.
 6. Произведите обновление приложения до текущего релиза (большая часть действий выполняется вручную).
 Обновите интерфейс. Выделите содержимое папки Update и скопируйте его с заменой в текущую директорию интерфейса.
 7. Для обновления базы данных откройте скрипт curr.sql в SQL Management Studio, выберите базу данных и выполните его.
 8. Убедитесь, что обновились 94 строчки.
 9. Обновите файл конфигурации соединения для веб-интерфейса с базой данных. В папке Update откройте файл web.config и в текущей директории интерфейса откройте такой же файл. В старый файл на место старых тэгов перенесите следующие обновленные тэги:
 Controls; assemblies; http modules; http handlers; locations (включая строку `</appsettings>`); modules (отвечает за "HTTPModule_Cache"); handlers.
 10. Обратите внимание на тег `<connectionString>`: в него необходимо дописать "MultipleActiveResultSets=false"
 Начальная строчка:
 `<add name="TCConnectionString" connectionString="packet size=4096;user id=D10TaskUser;data source=1F;persist security info=True;initial catalog=D10Task;password=msdn;Max Pool Size=500 " providerName="System.Data.SqlClient" />
` После изменения:
 `<add name="TCConnectionString" connectionString="packet size=4096;user id=D10TaskUser;data source=1F;persist security info=True;initial catalog=D10Task;password=msdn;Max Pool Size=500;MultipleActiveResultSets=false" providerName="System.Data.SqlClient" />
` 11. После выполнения всех этих действий  перезапустите пул приложения в IIS, а также сбросьте кеш и куки в обозревателе.
 12. Откройте приложение по адресу http://имясервера и убедитесь, что интерфейс обновился.
 13. Перейдите в режим администрирования и проверьте текущую версию приложения.
 14. Если при настройке IIS вы изменяли путь размещения каталога интерфейса, то в настройках приложения "Первая Форма" необходимо изменить несколько строк.
