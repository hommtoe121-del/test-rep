# Обмен данными на уровне MS SQL

Источник: https://help.1forma.ru/maintenance_guide/installation/databases/mssql/sql_smart/

В "Первой Форме" предусмотрена возможность обмена данными со сторонними приложениями на уровне MS SQL путем прямого вызова хранимых процедур SQL. Для этого используется SMART — смарт-действие Обновить параметры с помощью TSQL-вычислений. Его возможности описаны в Руководстве администратора.
 Смарт-действие «Обновить параметры с помощью TSQL-вычислений» позволяет выполнять произвольный SQL-запрос к базе данных системы и сохранять результат в параметрах задачи. Это позволяет интегрировать 1Ф с внешними системами через общую БД без разработки API.
